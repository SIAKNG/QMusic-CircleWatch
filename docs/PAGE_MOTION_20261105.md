# 1.1 页面轻动效与悬浮关闭修订

本轮在既有 1.1 基线后继续本地修订，保留版本名 1.1、版本代码 2、独立包名与现有签名。

## 实现

- 打开页面时新页面从右侧进入，返回时当前页面向右滑出，露出静止的上级页面；进入 160ms、返回 150ms。页面背景保持不透明，避免两页文字重影。转场期间可继续返回，不设置输入等待锁。
- 歌单和常用入口提供轻微按压反馈，按下缩至 98%，松开回弹；仅在按压和回弹期间启用缩放图层。列表测量尺寸不变，拖动取消点击。连续打开同一详情避免堆叠重复页面。
- 歌曲、歌单、缓存及播放列表的操作详情改用透明背景的悬浮关闭图标，移除固定的关闭操作区与文字。圆屏内容区由屏高的 70% 扩展至 82%，底部留出可滚出的避让空间；图标保留 44dp 触控区域。保存、取消与删除确认仍保留原来的明确操作。
- 不加入实时背景模糊、页面截图或窗口缩放，不改动歌曲业务、媒体会话和账号权限。

## 验证范围

自动回归覆盖分层返回、转场中立即返回、拖动歌单不误触打开，以及既有歌词、播放和媒体控制。原始设备截图、录屏和账号页面仅本地保存，不随源码上传。

实机帧采样包含界面创建与网络加载，样本波动明显；已有采样仍存在掉帧，不能据此承诺固定帧率或量化提速。该修订优先使用短过渡且允许中断，实际主观流畅度仍以设备使用为准。

本轮不替换 GitHub 源码或 Release，不改写已归档的 1.1 TXT；日常修订记入项目待发布台账，下一次明确升版时统一回顾。
