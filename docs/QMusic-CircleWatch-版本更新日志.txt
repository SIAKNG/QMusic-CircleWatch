QMusic-CircleWatch 版本更新日志

版本：1.1
首次更新日期：2026-11-04
更新日期：2026-11-07

主要更新：
1. 重点优化整体 APP 的使用流畅度与跟手性，改善页面打开、点击反馈、列表滑动等日常操作的响应，减少不必要的等待和界面刷新。
2. 优化表冠滚动表现，调整快慢旋转的速度反馈、短惯性与首次起转响应，让滚动阻尼和松手后的停顿过渡更自然流畅。
3. 优化页面打开、切换与逐层返回的动效，以及胶囊播放悬浮窗的展开和收起效果，让专辑图与容器的过渡更加连贯自然。
4. 优化网络请求与数据复用，缩短登录后用户资料、歌曲列表及歌单的加载等待，让内容更快显示，重复进入页面时更快响应。
5. 新增“支持媒体控制版”，在当前已验证的 OPPO 手表原厂媒体控制中显示歌曲、歌手、封面与应用图标，并支持播放、暂停及上下首操作。

6. 支持专辑封面取色，播放控件、进度环及歌词高亮随当前歌曲的封面自动变换配色，让播放界面保持统一。

支持媒体控制版安装说明：
支持媒体控制版使用与手表官方 QQ 音乐相同的应用包名，占用相同的安装位置，因此无法与官方 QQ 音乐共存。用户必须先卸载手表上的官方 QQ 音乐，才能安装此版本；卸载会删除官方应用的本地登录与下载数据。普通版可以与官方 QQ 音乐共存。

其他优化与修复：
1. 命名列表保留顶部标题与返回入口，播放队列搜索栏随滚动收起；右滑按页面层级返回。
2. 完善逐字歌词和双语翻译的自动加载与显示，长歌词完整换行，播放控件与歌词随专辑封面配色。
3. 修复播放进度、播放/暂停图标及歌词跟随的状态同步；操作菜单采用带叉号和“取消”文字的圆形悬浮按钮。
4. 完善完整歌单缓存、读取重试、账号隔离和旧请求结果处理，保留现有音乐功能与账号权益校验。


版本：1.0
首版日期：2026-10-30
更新日期：2026-11-01

新增：
1. 以 QMusic-CircleWatch 独立应用安装，可与原版并存；沿用本二创版本的数据和安装签名。
2. 新增可收起的迷你播放器：滚动时显示专辑圆标与实际播放进度，点击即可展开。
3. 接入 OPPO 手表原生短震反馈，支持表冠滚动时的触觉提示，并遵守系统振动设置。

优化：
1. 完善 OPPO 圆屏界面，统一胶囊选项、列表间距、比例边距、搜索、登录和确认弹窗，同时保留方屏布局。
2. 优化圆形播放控制布局，集中呈现播放、切歌、喜欢和队列等常用操作。
3. 顶部时间采用轻薄全宽半透明渐变，减轻滚动内容与时间的重叠干扰。
4. 支持逐字歌词和双语翻译，当前行稳定强调，其他歌词统一灰度；真实逐字时间驱动柔和的进度着色，无有效逐字时间时整行高亮。
5. 优化表冠灵敏度与反向转动反馈，合并和限速输入，改善快速滚动的稳定性。
6. 优化列表缩放与歌词绘制，减少不必要的界面更新，改善响应和流畅度。
7. 明确本应用的独立更新方式，避免误用原版安装包。

修复：
1. 修复圆屏边缘和弹窗中的内容、按钮遮挡问题。
2. 修复播放器长歌名与返回按钮重叠的问题。
3. 修复歌词高亮不稳定、换行后同步上色和整行完成后二次加深的问题。
4. 修复表冠快速或反向操作时的来回抽动，以及圆屏列表缩放引起的抖动。
