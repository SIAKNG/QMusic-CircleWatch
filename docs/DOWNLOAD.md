# 下载安装包

QMusic-CircleWatch 是 QQ 音乐安卓手表版第三方应用，适用于圆形表盘。当前版本提供两个安装包，请按是否需要 OPPO 原厂媒体控制选择。

## 1.1

### 普通版 · 可与官方 QQ 音乐共存

可以与手表上的官方 QQ 音乐同时安装。保留本应用的播放、歌词及标准 Android 媒体会话；当前 OPPO 原厂媒体控制面板不识别此版本。

文件：`QMusic-CircleWatch-1.1.apk`

[![下载普通版](buttons/download-standard.svg)](https://github.com/SIAKNG/QMusic-CircleWatch/releases/download/v1.1/QMusic-CircleWatch-1.1.apk)

[备用下载（同一安装包）](https://github.com/SIAKNG/QMusic-CircleWatch/blob/packages/安装包/1.1/QMusic-CircleWatch-1.1.apk?raw=true)

### 支持媒体控制版 · 不可与官方 QQ 音乐共存

**支持 OPPO 原厂媒体控制面板**，可显示歌曲、歌手与封面，并响应播放、暂停、上一首和下一首。

**必须先卸载手表上的官方 QQ 音乐，才能安装此版本。** 此版使用与官方应用相同的包名，无法共存；卸载会删除官方应用的本地登录和下载数据。

文件：`QMusic-CircleWatch-1.1-支持媒体控制版.apk`

[![下载支持媒体控制版](buttons/download-media.svg)](https://github.com/SIAKNG/QMusic-CircleWatch/blob/packages/安装包/1.1/QMusic-CircleWatch-1.1-支持媒体控制版.apk?raw=true)

[备用下载（同一安装包，页面明确标注“支持媒体控制版”）](https://github.com/SIAKNG/QMusic-CircleWatch/releases/download/v1.1/QMusic-CircleWatch-1.1-2.apk)

两个安装包的应用名称、图标和签名均属于本项目。两版账号与缓存各自独立，覆盖更新时需匹配已安装的包名和签名。媒体控制已在 OWW251 实机验证，Watch X3 尚未单独实测。

[查看 1.1 发布说明、完整工程与校验文件](https://github.com/SIAKNG/QMusic-CircleWatch/releases/tag/v1.1)
