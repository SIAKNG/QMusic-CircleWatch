# QMusic-CircleWatch 版本更新记录

## 记录规则

- 每个版本按「新增」「优化」「修复」三个部分组织，新版本放在最前，保留旧版本的日期与历史内容。
- 条目分别采用「新增了……」「优化了……」「修复了……问题」的表述，说明用户能感知的最终变化。
- 每次更新以此前正式发布版本为基线，只记录基线之后实际完成并验证的变化。
- 同一版本内对新增功能进行的反复修改合并为一条，以最终效果描述。实现过程与中间调整不另算更新。
- 同一版本多轮整理补充原有条目，避免重复建版本或重复计算功能。待发布变化单独登记，正式升版时统一归档。
- 未验证的能力、构建过程、测试日志、讨论与未来计划写入项目管理台账。更新正文不包含账号、密钥等私人信息。

**从 1.2 起，后续所有安装包默认支持 OPPO 原厂媒体控制。**

此版本无法与手表上的官方 QQ 音乐共存，安装前请先卸载官方版。

## 1.3 · 2026-11-25

### 优化

- 优化了会员信息显示的效果，方便用户直接确认自己的会员信息及到期时间。
- 优化了歌曲播放和网络缓冲时的等待时间，调整了加载状态下的动画效果，让用户明确看出歌曲正在加载。网络较差时临时使用较低音质播放；手动切歌或自动续播后，重新按默认音质加载。
- 优化了部分情况下安装包无法正常安装的问题及安装包的整体兼容性。

### 修复

- 修复了部分情况下登录二维码首次加载失败的问题，短暂网络异常时自动重试，并兼容较大的二维码图片响应。
- 修复了豪华绿钻与超级会员识别混淆、部分有效期缺失及旧会员缓存长期不刷新的问题。

## 1.2

首次更新日期：2026-11-13
更新日期：2026-11-15

### 新增

- 新增了微信扫码登录功能。
- 新增了歌单、我喜欢、最近播放和播放队列中的当前曲目高亮与定位功能，可从标题栏快速找到正在播放的歌曲。
- 新增了播放器音量控制面板，支持触屏细调。仅在面板打开时，旋转表冠才会调节音量。

### 优化

- 优化了播放器、展开胶囊和列表高亮曲目的长文字显示，过长的歌名和歌手名可滚动显示。展开胶囊第二行显示歌手。
- 优化了「播放选项」的滚动效果，返回按钮与标题同排显示，滚动后缩小并固定在顶部。触屏和表冠滚动均提供短促震动反馈。
- 优化了表冠调节音量时的档位切换和反馈，让连续调节更平稳。

### 修复

- 修复了部分情况下登录后歌曲不同步、收藏歌单加载不完整的问题。
- 修复了快速切换上一首、下一首时可能沿用旧曲进度的问题。手动切歌从头播放，同一首歌续播时保留进度。
- 修复了表冠滚动调节音量时指示条偶尔回跳的问题。
- 修复了外放确认弹窗有时无法关闭的问题。点击确认后立即收起弹窗。

## 1.1

首次更新日期：2026-11-04
更新日期：2026-11-07

### 新增

- 新增了“支持媒体控制版”，在当前已验证的 OPPO 手表原厂媒体控制中显示歌曲、歌手、封面与应用图标，并支持播放、暂停及上下首操作。
- 新增了专辑封面取色功能，播放控件、进度环及歌词高亮随当前歌曲的封面自动变换配色，让播放界面保持统一。
- 新增了操作菜单的圆形悬浮取消按钮，包含叉号和“取消”文字。

### 优化

- 优化了整体 APP 的使用流畅度与跟手性，改善页面打开、点击反馈、列表滑动等日常操作的响应，减少不必要的等待和界面刷新。
- 优化了表冠滚动表现，调整快慢旋转的速度反馈、短惯性与首次起转响应，让滚动阻尼和松手后的停顿过渡更自然流畅。
- 优化了页面打开、切换与逐层返回的动效，以及胶囊播放悬浮窗的展开和收起效果，让专辑图与容器的过渡更加连贯自然。
- 优化了网络请求与数据复用，缩短登录后用户资料、歌曲列表及歌单的加载等待，让内容更快显示，重复进入页面时更快响应。
- 优化了列表标题与返回入口的固定显示，播放队列搜索栏随滚动收起，右滑按页面层级返回。
- 优化了逐字歌词和双语翻译的自动加载与显示，长歌词完整换行，播放控件与歌词随专辑封面配色。
- 优化了完整歌单缓存、读取重试、账号隔离和旧请求结果处理，保留现有音乐功能与账号权益校验。

### 修复

- 修复了播放进度、播放/暂停图标及歌词跟随的状态同步问题。

安装说明

支持媒体控制版使用与手表官方 QQ 音乐相同的应用包名，占用相同的安装位置，因此无法与官方 QQ 音乐共存。用户必须先卸载手表上的官方 QQ 音乐，才能安装此版本；卸载会删除官方应用的本地登录与下载数据。普通版可以与官方 QQ 音乐共存。

## 1.0

首版日期：2026-10-30
更新日期：2026-11-01

### 新增

- 新增了以 QMusic-CircleWatch 独立安装的应用版本，可与原版并存，沿用本二创版本的数据和安装签名。
- 新增了可收起的迷你播放器：滚动时显示专辑圆标与实际播放进度，点击即可展开。
- 新增了 OPPO 手表原生短震反馈，支持表冠滚动时的触觉提示，并遵守系统振动设置。

### 优化

- 优化了 OPPO 圆屏界面，统一胶囊选项、列表间距、比例边距、搜索、登录和确认弹窗，同时保留方屏布局。
- 优化了圆形播放控制布局，集中呈现播放、切歌、喜欢和队列等常用操作。
- 优化了顶部时间的遮罩，采用轻薄全宽半透明渐变，减轻滚动内容与时间的重叠干扰。
- 优化了逐字歌词和双语翻译的显示，当前行稳定强调，其他歌词统一灰度。真实逐字时间驱动柔和的进度着色，无有效逐字时间时整行高亮。
- 优化了表冠灵敏度与反向转动反馈，合并和限速输入，改善快速滚动的稳定性。
- 优化了列表缩放与歌词绘制，减少不必要的界面更新，改善响应和流畅度。
- 优化了本应用的独立更新方式说明，避免误用原版安装包。

### 修复

- 修复了圆屏边缘和弹窗中的内容、按钮遮挡问题。
- 修复了播放器长歌名与返回按钮重叠的问题。
- 修复了歌词高亮不稳定、换行后同步上色和整行完成后二次加深的问题。
- 修复了表冠快速或反向操作时的来回抽动，以及圆屏列表缩放引起的抖动。
