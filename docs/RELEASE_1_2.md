# QMusic-CircleWatch 1.2

面向圆形表盘的 QQ 音乐安卓手表版第三方应用。

> **从 1.2 起，所有安装包默认支持 OPPO 原厂媒体控制。**
> 此前的非媒体控制版停止维护。此版本无法与官方 QQ 音乐共存，安装前请先卸载手表上的官方 QQ 音乐。

## 安装

APK 的应用包名为 `com.tencent.qqmusicwatch`，版本代码为 3，沿用本项目签名。

- 已安装本项目 1.1 支持媒体控制版时，可覆盖升级。
- 卸载官方 QQ 音乐会清除该应用在手表上的登录及下载数据。
- 已安装本项目独立共存版时，可保留原应用。两个包的账号和缓存各自独立，首次使用媒体控制版需单独登录。

发布附件包括 APK、源码 ZIP、更新 TXT、完整离线包和 SHA-256 校验文件。完整离线包保留安装包的中文文件名。

## 验证范围

已在 OPPO OWW251 核对安装、连续调节音量、播放选项的固定标题，以及触屏和表冠滚动的震动反馈。本轮使用真实账号验证了扫码登录和音乐库同步。Watch X3 及其他型号尚未单独实测。
