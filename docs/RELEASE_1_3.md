# QMusic-CircleWatch 1.3

日期：2026-11-25 · 状态：发布草稿，待审阅

**从 1.2 起，后续安装包默认支持 OPPO 原厂媒体控制。此版无法与手表官方 QQ 音乐共存，安装前需卸载官方版。** 本项目旧版本可直接覆盖更新，包名和签名保持一致。卸载官方版会清除其本地登录和下载数据。

### 新增

- 新增了透明底应用 Logo 开屏动画，随后平滑进入应用。
- 新增了歌曲加载提示，请求播放地址和缓冲期间显示旋转加载圆环及「加载中…」，正常播放后自动还原。

### 优化

- 优化了会员信息显示，豪华绿钻与超级会员分别显示为「豪华绿钻VIP」「超级会员SVIP」，后接「至YYYY.MM.DD」；较长内容完整换行，不省略名称和日期。
- 优化了歌曲起播和弱网缓冲的等待，网络较慢时临时降低本首歌曲音质并提示，切歌后重新使用默认音质。
- 优化了音质选项，仅保留标准、HQ、SQ，移除 Hi-Res；原 Hi-Res 默认设置自动调整为 SQ。
- 优化了诊断与日志入口，暂停「提交诊断」「分享日志」，按钮置灰不可点击；保留本地诊断检查、保存日志和清空日志。
- 优化了安装包签名兼容，提供 v1、v2、v3 签名供系统校验。

### 修复

- 修复了部分情况下登录二维码首次加载失败的问题，短暂网络异常时自动重试，并兼容较大的二维码图片响应。
- 修复了豪华绿钻与超级会员识别混淆、部分有效期缺失及旧会员缓存长期不刷新的问题。
- 修复了原版联系信息可能出现在公告或服务提示中的问题，过滤邮箱、QQ 群及相关联系内容。

## 安装与验证说明

- APK：`QMusic-CircleWatch-1.3-支持媒体控制版.apk`，版本代码 5，包名 `com.tencent.qqmusicwatch`。
- 如果系统只提示「未安装应用」，请参考 [安装排查](INSTALL_TROUBLESHOOTING.md) 获取具体错误码；签名兼容调整不能保证解决所有安装失败原因。
- 本版新增变更通过自动回归和发布构建校验；此前会员双账号、开屏及播放加载在 OWW251 验证。本次尚未进行 1.3 最终包的手表实测，不将受控网络测试等同所有真实弱网情况。
- 不包含签名私钥、真实账号资料、设备原始日志、腾讯官方 APK 或邮件服务部署文件。
- 这是审阅草稿，尚未发布为公众可下载版本。
