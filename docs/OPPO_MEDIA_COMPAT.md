# OPPO 固定名单兼容构建

2026-11-07 用户明确要求按 QQ 音乐包名尝试接入原厂媒体控制，并授权卸载表内官方版进行实测。本选项仍由同一个工程生成，不新增项目或仓库。

## 实际筛选机制

当前连接的 OWW251 原厂媒体控制通过 MediaSessionManager 获取活动会话，在选择会话与注册回调时，取 MediaController.getPackageName()，使用静态包名映射 containsKey 筛选。QQ 音乐条目为 com.tencent.qqmusicwatch。之后按播放状态选择会话并读取标准 MediaMetadata、PlaybackState，通过系统 TransportControls 控制播放。

相关筛选路径没有读取 APK 文件名、桌面名称，也没有发现签名证书或固定服务类名校验。因此改安装包文件名不能通过筛选，改变实际 applicationId 才可能生效。这是对当前固件代码的观察，不保证所有 OPPO 型号与系统版本使用相同规则。QQ 包名另有停止/暂停时零进度状态处理分支，不改变歌曲权限验证。

## 构建与身份

默认构建保持 com.qmusicwatch.round。显式使用 Gradle 参数 -PoppoMediaCompat=true，或项目管理/build.ps1 的 -OppoMediaCompat 开关，生成 applicationId 为 com.tencent.qqmusicwatch 的兼容 APK。界面、图标、第三方说明、代码命名空间、项目签名与版本仍属于 QMusic-CircleWatch，未使用官方签名，不接收上游原版 APK 更新。

两个包的数据各自独立，兼容包首次使用需要重新登录。兼容包不能与官方 QQ 音乐同时安装，也不能用本项目签名直接覆盖不同签名的官方版本。不要为默认版升级安装兼容包而宣称数据自动迁移。正式包不包含演示账号、展示入口或测试音源。

当前手表使用此兼容构建，后续覆盖更新必须仍使用相同包名及本项目签名，不能将默认独立包直接当作兼容包升级。原独立版保留为回退，不清除其数据。
