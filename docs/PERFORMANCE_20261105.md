# 1.1 性能优化与实测（2026-11-05）

版本仍为 1.1 / 代码 2。性能改动保留主界面、页面过渡、歌词逐字与双语显示、封面配色、播放胶囊、表冠和媒体业务。

## 已完成的修改

- 播放胶囊的动画值改在布局和绘制阶段读取，保留原有弹簧、尺寸、文字淡出及专辑居中轨迹。逐帧不再重组整段胶囊内容；播放进度在绘制与无障碍语义阶段读取，歌词预览只在所在行变化时更新。
- 播放器歌词的当前行索引使用派生状态，降低位置采样引起的上层重组。保留原有进度采样间隔和逐字帧动画。
- 波形播放按钮缓存不变的轮廓和测量路径，把旋转交给图层；图标反向补偿保持朝向，移除重复裁切。进度分段在绘制时更新，保持原来的形状、进度、按压和加载行为。
- 搜索、我喜欢、创建/收藏歌单、最近播放等主要列表补充内容类型；歌单分类结果按输入缓存。没有长按动作的图标使用单击识别器，保留有长按动作的入口及其触觉反馈。
- 已有首页和音乐库内存快照完整时，不重复解码账户缓存。音乐库归一化移到后台计算，并在返回 UI 前重新校验会话代次。设置快照在上游过滤重复值。
- 保留既有类预加载规则，补充界面方法规则，以及实机跟踪中出现即时编译的 19 个 Compose/集合/图片热点类。新规则由 AGP 合并并经 R8 重写；APK 同时包含 baseline.prof / baseline.profm。

- 歌曲、歌单等“更多”菜单按最新要求使用圆形悬浮取消按钮：叉号和“取消”文字同在圆形内，深色背景提升可视度。默认至少 48dp，并随系统字号留出空间；内容区保持扩展，末项保留滚动避让。

## 检查与验证

排查范围包括启动与状态恢复、主页/歌单/队列的滚动与输入、图片加载及取色、播放器/歌词/胶囊的状态与绘制、表冠分发、媒体事件、缓存与诊断后台工作、Release 压缩和预编译打包。保持既有业务与权限校验。

256 项单元与 Compose/Robolectric 回归通过，0 失败、0 跳过；Lint 0 错误、62 警告。新增回归覆盖圆形取消文字位于按钮内且点击能关闭菜单，并检查延迟读取进度后，进度值在胶囊折叠、展开时持续更新且仍只有一个专辑图。原有动画连续性、中途反向、拖动不误触、分层返回和媒体状态回归继续通过。

OWW251 / Android 11 保留数据覆盖安装；正式签名、包名、版本及安装文件哈希核对一致，清单权限与对照 APK 一致。性能采样版实机核对真实播放、切歌、进度、暂停图标、双语歌词自动推进、胶囊过渡和返回。交付包在其相同业务代码上增加圆形取消样式，并复核歌曲/歌单菜单取消、滚动末项避让。未将这些检查扩大为全部账号写入、离线缓存、蓝牙或 X3 的完整验收。

## 性能结果与边界

对照包为本轮之前的 1.1 页面动效包（11763f38…），性能优化采样包为 1eb0c177…；本次交付包为 fb888c6f…，只在采样包上追加圆形取消按钮样式与对应回归，未重新执行全套帧率量化。最后一组使用相同暂停歌曲、相同胶囊、同一“我喜欢”列表及 24 次脚本滑动，进入页面后等待 5 秒，再预热并采集。两包均带对应 DEX 元数据安装；最后额外对当前手表上的本应用执行了系统 speed 预编译。没有修改系统动画倍率或全局刷新率。

| 本次场景 | 对照包 + 基线编译 | 优化采样包 + 基线编译 | 优化采样包 + 本机完整预编译 |
|---|---:|---:|---:|
| 主线程帧回调平均耗时（ms） | 5.377 | 5.054 | 4.334 |
| P50 帧耗时（ms） | 8 | 9 | 9 |
| P90 帧耗时（ms） | 22 | 24 | 23 |
| P95 帧耗时（ms） | 30 | 32 | 28 |
| P99 帧耗时（ms） | 109 | 53 | 42 |
| gfxinfo 掉帧比例 | 17.30% | 22.91% | 29.34% |

本次主线程帧回调平均耗时下降约 19.4%，包含本机完整预编译的收益；不能把该数字描述为 APK 在所有设备上的帧率提升。长帧尾部缩短，但中位耗时和掉帧比例没有一致改善，尚未证明整体帧率大幅提升或稳定满帧。其他探索轮次的掉帧比例也有明显波动，完整记录保存在本地，对照不只挑选最好的样本。

Perfetto 记录前 24 秒的线程活动，gfxinfo 覆盖整组手势。脚本没有在采样中操作导航、发起新歌曲或录屏，但页面自身的后台同步、系统调度和缓存温度仍可能影响结果。此处是有限的真实使用路线采样，不是隔离网络、固定频率的实验室基准，也不把帧耗时倒数换算为实际 FPS。输入事件处理采样不等于完整点击到显示的端到端延迟。

启动测量也受预编译和文件缓存影响：对照在基线编译、路线预热后的三次进程冷启动为 589/581/587ms；新包同样预热后为 581/617/590ms，基本接近。完整预编译后的首次启动另记录为 530ms，不将不同预热条件的启动值混为同一百分比提升。

APK 内置规则供 ProfileInstaller 与系统后台优化使用；本机 speed 编译是针对当前安装实例的额外优化，不会使其他设备刚下载的 APK 自动变成相同编译状态。后续覆盖安装可能重新生成编译产物。
