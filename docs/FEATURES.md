# 功能与使用说明

## 发现与音乐库

发现页提供每日推荐和搜索入口；“我的”页集中访问喜欢、自建与收藏歌单、最近播放、缓存及设置。歌单详情可以播放歌曲、播放全部并提交缓存任务。曲目菜单保留喜欢、加入歌单等原工程操作，实际结果取决于账号和服务权限。

搜索支持关键词、历史记录和结果列表。扫码页沿用原工程授权流程，二维码须在有效期内通过页面提示的手机端完成授权；截图中的二维码仅演示排版，不能登录。

## 播放与队列

Media3 提供在线播放、暂停/继续、上一首/下一首、进度控制与后台播放。顺序、单曲循环、列表循环和随机模式可在设置或播放菜单中选择。队列页显示当前曲目并保留队列管理能力。睡眠定时、耳机提醒、自动打开播放页等选项沿用原有实现。

底部迷你播放器显示曲名、封面和播放控制。列表滚动时自动收起为专辑圆标，圆环按实际播放位置推进；点击圆标展开，展开状态点击进入播放页。

1.1 的展开与收起共用同一张专辑图和进度环，随容器收缩连续移到中央，展开时返回原位；快速反向操作可以从当前动画位置接续。

播放队列的标题和搜索框随列表滚动收起，顶部保留紧凑标题与返回入口；歌单、喜欢、最近播放及其他命名列表同样保留固定标题，方便确认当前位置和返回。

音质按账号权益和可用音源展示，支持的标准、HQ、SQ 仍需满足相应服务条件；Hi-Res 保留能力说明，不宣称本客户端已支持播放。无权限时继续显示原有提示。

## 歌词

播放器可切换到歌词页。支持逐字歌词与双语翻译，原文和译文可以分别显示或隐藏；可调整字号、对齐方式、时间偏移及动画设置。当前行稳定强调，其余歌词保持同一灰度。

长歌词自然换行并向下延伸，不限制行数、不以省略号截断；超过一屏时可滚动阅读。当前逐字歌词未播放部分以白色显示，已播放部分按真实时序填入封面主题色。播放控件、进度环和歌词的强调色从当前歌曲封面提取，换歌或封面变化时重新取色，并处理黑色背景下的可读性；封面不可用时使用默认强调色。

恢复上次歌曲或进入歌词页时自动加载，重复请求合并，短暂失败有限重试；有效歌词按账号隔离缓存，快速切歌时旧请求结果不会覆盖新歌。

有有效 QRC 逐字时间时，按真实时间依次推进，换行后继续到下一行，颜色交界处做柔和过渡。没有有效逐字时间时仅整行高亮，不用固定速度模拟逐字。帧动画只触发必要的绘制更新。

## 圆屏、表冠与振动

列表使用圆屏安全边距与边缘缩放，选项卡为胶囊形，确认弹窗提供圆形按钮。时间区域使用薄型透明渐变和阴影压暗重叠内容。方屏使用既有分支，不需要另装一个 APK。

每日推荐与“我的”构成主界面。从左侧边缘向右滑动时，下级页面先返回上一页，直至回到主界面后才退出应用；系统返回键沿用同一页面层级。中间区域的左右滑动仍用于主界面与播放器翻页。

页面打开与分层返回使用短促的定向滑动，上级页面保持静止，由当前页面滑入或滑出；歌单及常用入口提供轻微按压反馈。缩放图层仅在按压及回弹期间启用，不改变列表排版尺寸，拖动时取消点击；动画过程中可以继续返回，不需要等待动效结束。歌曲、歌单、缓存与播放列表的操作详情使用透明背景的悬浮关闭图标，内容可在其下方滚动；滚到末尾时保留避让空间，避免最后一项被挡住。

OWW251 支持实体表冠滚动；列表输入经过合并、限速和反向噪声过滤，减少快速转动造成的来回跳动。播放器保留表冠音量开关。OPPO 原生短震在系统允许且设备支持时启用；关闭系统触觉反馈时遵守系统设置。

表冠快转提供更高滚动速度，松手后保留短距离惯性；起转时先应用输入，减少启动等待，触摸与明确反向转动可中断已有惯性。标准媒体服务与原厂音乐应用选择页的适配边界见 [媒体兼容说明](MEDIA_COMPATIBILITY.md)。

## 缓存与设置

缓存页面显示已完成与等待/进行中的任务，保留仅 Wi-Fi 缓存和缓存管理。显示设置组织界面字号、歌词和主题；播放设置组织音质、模式、睡眠定时、耳机提醒与表冠；网络设置组织推荐数量、缓存和连接相关选项；关于页提供版本、二创来源与本版更新提示。

界面存在不代表线上服务始终可用：域名解析、上游接口、登录状态、曲库版权与会员权益都会影响实际结果。未通过全部账号写入、缓存和蓝牙组合测试，详见 [原版对比与验证边界](UPSTREAM_DIFF.md)。
