# 与原版相比改了什么

对照对象为本工程导入的 [huanghao897/QMusicWatch](https://github.com/huanghao897/QMusicWatch) **0.9.14** 快照（本地基线提交 `7cc6bf2`）。不是对原作者后续每一次提交的比较。原版已经具备音乐业务、部分圆屏布局、表冠操作与逐字歌词；下面明确区分保留与本版改进。

| 范围 | 原版基础 | QMusic-CircleWatch 1.1 的主要变化 |
| --- | --- | --- |
| 圆表布局 | 已有圆屏安全边距与播放条 | 结合 OPPO 圆表资料统一比例边距、列表、标题、二维码、搜索、弹窗和控制布局；保持方屏分支 |
| 列表与选项 | 已有列表和圆角控件 | 选项统一胶囊形；收紧间距，按圆形可见区域进行绘制层缩放，保持测量高度稳定；命名列表固定标题与返回入口，队列搜索随滚动收起 |
| 顶部时间 | 已有时钟显示 | 薄型全宽半透明渐变遮罩与文字阴影，软化进入时间区的滚动内容；Android 11 上不依赖实时背景模糊 |
| 底部播放入口 | 已有底部播放条 | 滚动时收起为专辑圆标，描边显示真实播放进度；点击展开，再点击进入播放器 |
| 播放器 | 已有播放、切歌、喜欢、队列等操作 | 调整圆形布局和长标题避让，统一圆表触控与返回入口；控件与进度随封面取色，补全标准媒体浏览与队列命令，原厂名单限制另见媒体兼容说明 |
| 歌词 | 已有歌词、翻译与逐字数据解析 | 自然换行完整显示与稳定强调；跨行按真实 QRC 时序推进，白色底字逐步填入封面色，无有效时序则整行高亮；统一非当前行灰度与柔和进度边界；自动加载、重试及账号隔离缓存 |
| 动画性能 | 已有动画与性能采样 | 歌词推进放到绘制阶段，减少列表重组；移除空闲逐帧性能轮询，使用窗口帧指标；稳定列表缩放中心与尺寸 |
| 实体表冠 | 已有表冠和音量控制 | 适配 OWW251 鼠标式滚轮与编码器输入；快转加速、有限惯性、首段输入及时应用及反向噪声过滤，按可见区域分发 |
| 振动 | 已有部分触觉反馈 | 接入 OPPO 线性马达短震效果 302，按滚动距离及时间节流，尊重系统触觉开关；不支持时安全回退 |
| 安装与更新 | 原版包名、签名及更新渠道 | 统一名称与本项目签名；提供 com.qmusicwatch.round 独立共存版及 com.tencent.qqmusicwatch 媒体控制兼容版，隔离上游 APK 更新 |
| 文档与交付 | 原版 README、许可证和说明 | 独立功能文档、对比表、原生实机演示图库、完整版本历史与双版本 1.1 安装包；每个版本附下载入口 |

搜索、扫码登录业务、账号权益、歌单和收藏、缓存、Media3 播放等主要业务沿用原工程，并未在二创中发明新的音乐服务或绕过会员权限。

## 验证范围

OWW251 实机已验证搜索、在线播放、暂停、歌词、迷你播放器收起与展开、时间区和圆表列表。用户实体慢转、快转与反向旋转表冠确认正常滚动、短震且不再来回抽动，系统记录到效果 302。自动回归与静态检查另见本次交付说明。

1.1 兼容版重新扫码、资料与歌单读取、播放和原厂媒体控制已在 OWW251 实测；X3、收藏/歌单写入、真实离线缓存、蓝牙及全部会员音质组合尚未逐项完成实机验收。保留功能实现不等于所有在线条件都已验证。
