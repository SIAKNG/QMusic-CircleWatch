本版重点

  • OPPO 圆表布局、胶囊列表与轻薄渐变时间区。
  • 滚动收起的专辑圆标及真实进度环。
  • 三行歌词、真实逐字时序、柔和进度边界与稳定高亮。
  • 表冠输入过滤、滚动限速与 OPPO 原生短震。
  • 独立安装、签名与更新，保留原有音乐业务。
