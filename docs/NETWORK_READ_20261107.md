# 账号与歌单读取优化

2026-11-07 本地修订，版本仍为 1.1。未同步 GitHub Release。

## 完成内容

- HTTP 使用可取消的异步读取，响应体读取与解析在网络工作线程完成；退出页面、切换账号或取消请求时关闭相应连接。
- 个人资料中的昵称与头像、创建与收藏歌单目录先显示，不再等待全部喜欢歌曲或会员信息读取完毕。最终会员与播放权限仍按完整校验结果处理。
- 已知总数且分页规则稳定的大歌单最多同时读取两页，按原顺序合并；遇到服务器页大小或总数变化则退回顺序读取，不跳过歌曲。完整读取后才更新歌曲列表与播放队列。
- 合并重复读取，短时间重进复用完整结果；详情缓存最多两份、合计不超过 3000 首，账号切换或本地修改后失效。已有完整内容可在刷新期间继续显示。
- 加载时显示已读取数量和重试入口，避免将加载中显示为空歌单；账号缓存归一化移到后台，保留会话代次与账号隔离检查。
- 网络诊断只记操作名称、耗时、状态码与数量，不记录账号、请求内容或连接凭据。

## 实机结果与范围

OWW251 保留现有扫码登录会话，使用当前网络读取官方内容。系统默认链路为手机代理（COMPANION_PROXY），设备另有 VPN 网络；未更改网络设置。

同一份 2582 首歌单，旧包首次完整列表出现在轮询的 28.4–31.3 秒区间；新包出现在 18.5–22.8 秒区间。新包应用内完整读取计时为 19.781 秒，随后立即重进记录为缓存命中、2582 首。轮询会引入观测延迟，这些是单次现场对照，不代表所有网络或所有账号都能获得相同提速。

新包本轮喜欢歌曲完整读取 2653 首，用时 22.653 秒。目录与进度提前显示，正式播放队列没有使用未完成的分页结果。多次请求 HTTP 200，连接复用后的分页请求无需再次 DNS/TLS；初建连接和远端响应仍有实际网络成本。

自动回归覆盖乱序并发的有序完整合并、分页大小变化回退、未知总数串行、取消请求、缺页报错、资料权限合并与目录提前返回。真实账号写入、重新扫码全流程、离线缓存、蓝牙设备与 Watch X3 不在本次实机验收范围。未将本轮网络提速扩大解释为整体稳定满帧。

原始账号界面、设备日志、厂商二进制和录屏只在项目本地测试目录保存。
