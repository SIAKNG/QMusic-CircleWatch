# 安装失败排查

手表安装器显示“未安装应用”时，该提示本身无法区分签名冲突、版本冲突、文件损坏或空间不足。

本项目从 1.2 起默认使用 `com.tencent.qqmusicwatch` 包名接入 OPPO 原厂媒体控制，沿用本项目签名。安装前需卸载手表上的官方 QQ 音乐。与其他来源的同包名客户端也无法相互覆盖安装。卸载会清除被卸载应用的登录及下载数据。

已经安装本项目、签名相同的媒体控制版，可直接覆盖升级。独立共存版的账号与缓存各自独立。

先核对下载文件的 SHA-256 与安装包附带的校验文件，再确认手表存储空间。如果依然无法安装，可在电脑启用手表 USB 调试，用项目内脚本获取系统实际错误码。

```powershell
.\tools\install-watch.ps1 -Apk '安装包的完整路径.apk' -Serial '手表的 ADB 序列号'
```

脚本执行覆盖安装，并显示系统结果。常见错误含义如下。

| 错误码 | 原因及处理 |
| --- | --- |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 同包名应用签名不同，确认冲突应用来源后再处理。 |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 已安装版本代码高于待安装包，核对版本与来源。 |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | 可用空间不足。 |
| `INSTALL_PARSE_FAILED_*` / `INSTALL_FAILED_INVALID_APK` | 核对文件完整性及签名。 |

现有 1.2 发布包已在连接的 OWW251 上通过覆盖安装。其他用户提供的截图只显示通用失败提示，其设备上的具体原因仍需系统错误码确认。
